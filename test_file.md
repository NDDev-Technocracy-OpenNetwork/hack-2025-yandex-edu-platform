# Тестовый файл

Это тестовый файл на **русском языке** для проверки парсинга MD файлов.

## Список тестовых элементов:

- Первый элемент 
- Второй элемент
- Третий элемент с `кодом`

**Жирный текст** и *курсив* должны работать корректно.

> Это цитата на русском языке

```javascript
// Блок кода
console.log('Привет, мир!');
```

Обычный текст для тестирования парсинга markdown файлов с русской кириллицей.
